// Component Relationships & Data Flow
Page Template > CRUD Template: Wraps & Provides Layout
CRUD Template > Data Table: Renders Data & Captures Actions
CRUD Template > CRUD Dialog: Opens Forms for Create/Edit
CRUD Template > Entity Detail Dialog: Opens Detail Views
Data Table > CRUD Template: Triggers Actions (Edit/Delete/View)
CRUD Dialog > CRUD Template: Submits Form Data
Entity Detail Dialog > CRUD Template: Optional Update Requests

// User Interaction Flow
User > Page Template: Access Page
User > Data Table: View & Interact with Data
User > CRUD Dialog: Create/Edit Records
User > Entity Detail Dialog: View Full Details

// Data Flow
CRUD Template > Data Table: Provides Data & Handlers
CRUD Template > CRUD Dialog: Manages Form State
CRUD Template > Entity Detail Dialog: Provides Record Data
